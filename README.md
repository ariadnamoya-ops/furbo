# Web de La Liga

**Integrantes:** [NOMBRE 1] y [NOMBRE 2]

**Tema:** La Liga (fútbol español)

## Descripción
Web sencilla de tres páginas hecha para practicar Git y GitHub en la optativa Git y GitHub (ASIX, Escola Balmes).

## Archivos y páginas
- `index.html`: página de presentación
- `equipos.html`: cuatro equipos de La Liga
- `partidos.html`: tabla de resultados (datos de ejemplo)
- `css/style.css`: colores, fondos y tipografía
- `js/script.js`: botón que muestra un mensaje

## Cómo abrir la web
1. Clona o descarga el repositorio.
2. Abre el archivo `index.html` con doble clic (o con el navegador).
